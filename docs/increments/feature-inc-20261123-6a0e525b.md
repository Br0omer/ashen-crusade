# feature/inc-20261123-6a0e525b — RIFLES-B1: изолированный прототип винтовок A и B1

## Цель
Добавить отдельную страницу `prototypes/rifles-b1/` с игрой на базе ARCH-06.2, где винтовка A ведёт себя как прежде, а винтовка B1 бьёт сквозь до 3 целей по траектории пули; принятые сборки не менять.

## Критерии приёмки
Страница `prototypes/rifles-b1/index.html` с собственной версией (`js/version.js`, `build.json`, `1.1.0-rifles-b1.1`) и без устаревших описаний ARCH-06.2. Ввод, проекция, визуал героя, диагностика, boot, CSS и графика читаются из `arch062/` без копий; пути относительные страницы и работают под любым префиксом (GitHub Pages `/ashen-crusade/` или корень локального сервера), включая `Image.src`. `arch062/`, прочие сборки, `docs/releases.md`, инфраструктура и ART-02a не изменены. Волны, враги, меч, рывок, импульс, лечение и визуал сохранены.

1. Винтовка A: урон 27+2×уровень в момент попадания, `p.fire=.17`, скорость 780, жизнь .8 с, радиус `e.r+5`, отбрасывание .12 с, дискретная проверка конца шага и одна цель. Покадрово совпадает с реальным arch062 (время, позиции, параметры, первый hit, урон, отбрасывание).
2. Винтовка B1: урон `max(36, 27+2×уровень)` в момент попадания, `.40` с, те же скорость, дальность, радиус и отбрасывание. Каждый снаряд хранит `Set` уникальных экземпляров и `remaining=3`.
3. Пересечение сегмента пути за тик с кругом цели по ПЕРВОМУ времени входа `t∈[0,1]`: старт внутри (t=0), касание, обрезка у конца дальности. Цели сортируются вдоль сегмента; при равном t порядок задаётся геометрией и идентификатором, а не позицией в массиве. Повторных ударов по одной цели нет; два снаряда независимы.
4. RB/RT через настоящие `input()`/`update(dt)`: смена по фронту до выстрела (muzzle и `elevationPx` нового оружия), общий `p.fire` не сбрасывается, пауза блокирует смену и выстрел. Профиль, цвет и лимит снаряда сохраняются при смене винтовки в полёте.
5. След снаряда: A янтарный `#ffcc72`, B1 бирюзовый `#4fe3d2`. Вспышка и поза стрельбы около .07 с и не зависят от `p.fire`. Рестарт сбрасывает снаряды, `p.fire` и вспышку.
6. Открытие: после merge `https://br0omer.github.io/ashen-crusade/prototypes/rifles-b1/`; локально — любой статический сервер из корня репозитория, например `python3 -m http.server 8000`, затем `http://localhost:8000/prototypes/rifles-b1/` (страницу открывать как каталог со слэшем; `file://` не годится из-за чтения пикселей картинок). PR сам по себе тестовой ссылки не создаёт.
