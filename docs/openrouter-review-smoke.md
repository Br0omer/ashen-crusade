# Smoke test: независимый OpenRouter PR-ревьюер

Этот документ добавлен **только для проверки инфраструктуры ARCH-07.3**.

Ожидаемый результат:

1. При открытии PR из этой ветки GitHub Actions запускает `Contract tests`.
2. После успешного CI запускается `OpenRouter AI review`.
3. Проверка читает фактический diff и описание PR.
4. В обсуждении PR появляется комментарий бота с вердиктом.
5. На текущем коммите появляется check `OpenRouter AI review`.

Границы теста:

- Ни одна игровая сборка, игровой код, настройки GitHub Pages или принятый артефакт не меняются.
- Тест не означает художественной или геймплейной приёмки.
- Файл не нужно включать в `main`: тестовый PR можно закрыть после проверки.
