# Пепельный крестовый поход — план разработки

## Правила
- Направление → задача → реализация → публикация → тест на Galaxy Tab S9+ с Xbox Series Controller → приёмка.
- Проверенные версии сохраняются отдельными адресами. Не изменять уже принятую сборку.
- Публикация кода сама по себе не означает приёмку задачи.
- Для художественной анимации техническая работоспособность не заменяет визуальную приёмку. Сначала отдельный цикл поз, затем интеграция.

## Направления
- ARCH — архитектура и инфраструктура
- ART — персонажи и анимации
- MAP — окружение и локации
- COMBAT — боевая система
- AI — поведение противников
- RPG — прогрессия
- LOOT — инвентарь и экипировка
- UI — интерфейс и геймпад
- AUDIO — звук
- CONTENT — контент и миссии
- QA — тестирование и производительность
